ТРАНСКРИБАТОР ШЧСМ — Windows 10/11

ВАЖНО ПРО ПРОВЕРКУ РЕЗУЛЬТАТА (22.09.2026)
  В версии для Windows программа пишет «готово», даже если часть речи
  потерялась: проверки полноты расшифровки здесь пока нет (в версии для
  Mac она есть). Исправление ждёт проверки на компьютере с Windows.
  Поэтому ПОСЛЕ КАЖДОЙ расшифровки прослушайте начало записи и сравните
  её с текстом: если речь есть, а в тексте её нет — запустите ещё раз,
  а если повторится — напишите нам, приложив имя файла.

СНАЧАЛА РАЗБЛОКИРУЙТЕ АРХИВ — до распаковки:
  правый клик по скачанному ZIP → «Свойства» →
  внизу галочка «Разблокировать» → «Применить».

  Windows помечает всё скачанное как «из интернета» и потом
  не даёт запускать файлы изнутри. Если пропустить этот шаг,
  установка может молча не сработать.

Дальше два простых шага:

  1. Дважды щёлкните   1-Install.bat     — установка (один раз, несколько минут).
     Если появится синий экран «SmartScreen» →
     нажмите «Подробнее» → «Выполнить в любом случае».

  2. Дважды щёлкните   2-Transcribe.bat  — расшифровать аудио в текст.

После установки на Рабочем столе появится папка «Транскрибатор ШЧСМ»:
  • «Положите аудио сюда»  — киньте туда лекцию или голосовое
  • «ТРАНСКРИБИРОВАТЬ»      — дважды щёлкните
  • «Готовые тексты»        — заберите готовый текст

Что важно знать:

  • Всё считается у вас на компьютере. Запись никуда не отправляется,
    интернет нужен только один раз — при установке.

  • Имена ачарьев и санскритские термины программа пишет по словарю ШЧСМ.

  • Машина только помогает. Где она могла ошибиться, в конце текста
    появляется пометка «ПРОВЕРЬТЕ ЭТИ МЕСТА» — эти места нужно
    послушать в оригинале. Слово Гуру машиной не правим.

  • Рядом с текстом появляется файл .srt — тот же текст, но со временем.
    По нему удобно найти нужное место в записи.

  • Время зависит от длины записи: короткая — минуты, часовая лекция —
    от 40 минут, а на слабом компьютере дольше. Это нормально.
