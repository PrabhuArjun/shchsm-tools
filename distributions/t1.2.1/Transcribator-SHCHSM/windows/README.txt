Транскрибатор ШЧСМ для Windows — T1.2.1
Windows 10/11, 64-разрядная (x64).

1. Полностью распакуйте ZIP. В папке windows откройте 1-Install.bat.
   Подтвердите запрос Windows, если появится, и дождитесь «ГОТОВО».
   Нужен интернет: загрузится около 1,8 ГБ.
2. На Рабочем столе откройте «Транскрибатор ШЧСМ».
   Положите запись в «Положите аудио сюда», откройте «ТРАНСКРИБИРОВАТЬ.bat».
3. Готовый текст и субтитры находятся в «Готовые тексты».
   Сверьте имена и цитаты с записью.

Распознавание выполняется на вашем компьютере. После установки интернет не нужен.
Если файл уже расшифровывали, новый результат сохранится с отдельным номером.
